## 一句话版本

一个空 = 一条记录。记录只承载原始事实（题干、答案）与一次分析的产出
（板块、答案形式、判断依据），其余一切都是这两样东西的派生物，可以随时重算。

这个应用要答的是「**这一类空该填成什么形态**」，不是「你错得怎么样」。
错误率、加权失分、成熟度门槛这类统计在 v3 被整层删掉了——它们答的是后一个问题。
